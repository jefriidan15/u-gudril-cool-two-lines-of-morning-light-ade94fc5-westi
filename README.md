A two-line micro poem about light and morning, written for the
[make.fun bounty "Two Lines of Morning Light"](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5).

## The poem

> Sunlight threads the keyhole, one thin needle,
> and stitches the dark room to morning.

One image carries both lines: morning light arriving through a keyhole,
a single thin needle of it, stitching the dark room to the day. The second line
opens the image instead of restating it, and leaves unsaid what the
stitched-together morning will bring.

## How it works

`main.py` (Python 3.13 standard library only, no network, deterministic)
writes the poem to `/output/entry.txt` — UTF-8, exactly two lines,
well within the 120-character limit.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
